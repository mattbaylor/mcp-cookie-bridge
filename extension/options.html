MCP Cookie Bridge — Settings

Define one or more profiles (host + cookie combos). Settings are stored in the extension. Export the JSON and place it at the MCP server's config path too (the server reads a file, not this UI).

Replicating across a team? Configure once, click Export JSON, and share the file. Others click Import JSON. If the imported file has no bridgeToken, a per-device one is generated automatically.
